# Single cell multi-omic whole genome sequencing and chromatin accessibility profiling reveals genome-epigenome coevolution in colorectal cancer

This repository contains the bash and R code used to process and analyse the data generated as part of the study *"Single cell multi-omic whole genome sequencing and chromatin accessibility profiling reveals genome-epigenome coevolution in colorectal cancer"* [1]. The source data referred to within the R scripts can be found alongisde the publication.

## References
- [1] Mossner, M., Colson, C., Guo, Q., Whiting, F., Grant, H., Stafford, A., ... & Graham, T. A. (2025). Single cell multi-omic whole genome sequencing and chromatin accessibility profiling reveals genome-epigenome coevolution in colorectal cancer. bioRxiv, 2025-04.
